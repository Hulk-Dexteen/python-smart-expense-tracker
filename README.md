
# Python Smart Expense Tracker

A Python-based expense tracking application designed to help users record, organise and analyse their daily spending.

## Features

- Add expenses with dates, descriptions, categories and amounts
- View recorded expenses
- Save expenses to a CSV file
- Automatically load saved expenses when the program starts
- Calculate overall spending and spending by category
- Search expenses by category
- Validate inputs and handle file errors

## Technologies Used

- Python 3
- CSV module
- Decimal module
- File handling
- Dictionaries and lists
- Exception handling

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python expense_tracker.py
```

The application uses a menu-based interface to manage expenses.

## How It Works

Expenses are stored as Python dictionaries and saved to a CSV file. When the application starts, it loads the previously saved records.

The program uses Decimal for accurate financial calculations and includes validation to help prevent invalid entries.
